# Новые персонажи из других программ

Место для **неимпортированных кандидатов пользователя**, не папка runtime. Создавать отдельную папку `YYYY-MM-DD_Character_Tool_Revision` и оставлять предыдущие версии.

Внутри: исходный native файл, FBX/GLB, все текстуры, скриншот/preview, короткий SOURCE.md (какой инструмент, дата, лицензия/условия использования, масштаб, axes, skeleton/animations, что изменено). Не включать токены/пароли сервиса.

Результат не становится активным из-за копирования сюда. Сначала проверить масштаб/геометрию/UV/rig, выбрать candidate, затем отдельный импорт в новую Content-папку, код/коллизии и регрессии. Генераторы create_crew_* не предназначены для редактирования внешнего меша.
