## 1. Краткое состояние

На данный момент создан нативный Unreal Engine 5.8.2 C++ проект с first-person управлением, сервер-авторитетным переносом грузов, тремя специальными типами груза, контрактом смены, спасением упавших игроков/грузов, аварией с течью, ремонтом, деградацией освещения, детерминированным emergency director, локальным interior cutaway и автоматизированными сетевыми проверками.

## 2. Идентичность и рамки продукта

Название: **Calmy Pirates Co.**

Жанр и цель: современная 2–4 player physical co-op comedy на небольшом коммерческом грузовом судне. Это не fantasy pirate game.

Основной доказанный игровой цикл:

```text
move -> grab -> carry -> throw -> impact -> temporary knockdown -> recovery
```

Ближайшая продуктовая цель: полноценная first-person совместная игра внутри большого судна, где интерьер, машинные помещения, палубы и маршруты являются главным игровым пространством.

Не заявлено и не доказано:

- завершённая игра;
- AAA/production-ready арт;
- человеческий fun gate;
- полноценный voyage loop длительностью 12–20 минут;
- Internet matchmaking/lobby;
- качественная физика судна, плавучесть и движение;
- production character, animation, audio и UI;
- четырёхпользовательский soak под задержкой/packet loss;
- Shipping release.

## 3. Обязательные правила проекта

Правила из `AGENTS.md`, которые нельзя нарушать:

- Engine baseline — Unreal Engine **5.8.2**, пока миграция явно не согласована.
- Host/server владеет gameplay outcome; клиент отправляет валидируемое намерение и владеет input/camera/cosmetic feedback.
- Carry lifecycle сохраняется как `Free -> Reserved -> Held -> Thrown -> Free`.
- Player lifecycle сохраняется как `Controlled -> KnockedDown -> Recovering -> Controlled`.
- Для каждого RPC документируются caller, receiver, validation, duplicate behavior, late join и disconnect behavior.
- Greybox и измеримая игровая ценность важнее массовой загрузки ассетов и раннего polish.
- Unreal MCP остаётся только на loopback. Нельзя открывать его наружу или менять Firewall ради MCP.
- Нельзя редактировать `.uasset` и `.umap` как текст.
- Нельзя заявлять human fun gate без реальных игроков.
- Gameplay change не завершён без релевантных automation и Host/Client evidence.
- Нельзя самостоятельно push/merge/rewrite history, удалять корни проекта или включать обходные permissions.

Дополнительное правило для большого судна после аудита:

- Наличие объекта по имени или количество деталей не означает PASS.
- Для игровой зоны нужны общий кадр, минимум два close-up с разных сторон, проверка входа/выхода, отсутствие видимых пересечений и first-person collision test в Unreal.

## 6. Реализованные gameplay-системы

### Character и сетевое управление

- `ACalmyCharacter` использует Enhanced Input и `CharacterMovement` prediction/correction.
- First-person camera и camera-relative movement проверены отдельным automation test.
- Серверные RPC: `ServerGrab`, `ServerDrop`, `ServerThrow`, `ServerRestart`, `ServerHandoff`, `ServerRepair`.
- Команды защищены sequence/rate gate, проверками мира, дистанции, line of sight, текущего round и состояния персонажа/груза.
- Knockdown вызывается быстрым брошенным грузом: 1.2 с down + 0.7 с recovering.
- Knockdown пока визуальный tilt и movement lock, без ragdoll.

### Груз

`ACalmyCargo` поддерживает:

- Standard;
- Bulky — нужен второй свободный игрок рядом и с line of sight, carrier speed 260 cm/s, throw запрещён, потеря помощника через 1 с вызывает drop;
- Unstable — теряет 20 stability/s в руках, восстанавливается в покое, поддерживает Q handoff;
- Fragile — получает impact damage, меняет цвет и проигрывает placeholder procedural cue.

Holder/reservation, condition, reset count и delivery state реплицируются. Клиент не задаёт integrity, stability, payout или delivery totals.

### Контракт смены и экономика

- Три заданных ящика должны полностью войти в delivery zone и успокоиться 0.75 с.
- Server-owned timer: 300 с.
- Payout: `$1200 + 4 * seconds remaining - 125 * rescues - 300 * damaged deliveries`.
- Минимальная успешная выплата: $250.
- Rating: 1–3 stars.
- Failed contract: payout 0.
- Remote client не может перезапустить host round.
- Late join получает актуальный replicated snapshot.

### Rescue

- Игрок, выпавший через открытый gangway/за границы, возвращается в свободный безопасный слот.
- Held cargo возвращается домой вместе с incident handling.
- Thrown/lost cargo также возвращается.
- HUD считает rescue событий игроков и грузов.

### Leak и ремонт

- Warning начинается через 18–24 с после старта.
- Warning длится 5 с, затем активируется течь.
- Water растёт на 2 percentage points/s, максимум 100.
- При 30% включается server-derived `bPowerDegraded`: локальное затемнение/desaturation, красный task light клапана и синий task light delivery zone.
- При 50% скорость всех игроков уменьшается на 30%.
- Ремонт: пустые руки, grounded, stationary, до 1.8 м, line of sight, hold `F`.
- Repair rate: 20 points/s; partial progress сохраняется.
- Heartbeat lease: 0.65 server seconds; disconnect/invalid worker освобождает клапан.
- После 100% leak sealed; water уходит на 10 points/s.
- Cooldown следующего события: 45–60 с.
- Максимум два события на контракт; stacking запрещён.
- Development seed: `-CalmyEmergencySeed=<positive integer>`, network suite использует 203.

### Interior cutaway

- `ACalmyInteriorCutaway` скрывает roof panels локально только для игрока внутри.
- Weather deck и sea occluder также локально скрываются ниже палубы.
- Один split/network player не меняет видимость другому.
- Server rescue bounds включают нижнюю палубу, сохраняя реальный overboard recovery.

## 15. Version control и backup risk

`E:\Game\CalmyPiratesCoUE` является Git working tree на branch `main`, но **в репозитории ещё нет ни одного commit** и нет настроенного remote. Все 24 верхнеуровневые позиции сейчас untracked.

Это самый большой operational risk: существует рабочий проект и много локальных build/art assets, но нет нормальной истории изменений или remote backup.

Нельзя автоматически добавлять огромные `Builds`, `Saved`, `Intermediate`, `DerivedDataCache` и generated binaries в Git. Перед первым commit проверить `.gitignore`, решить LFS/asset storage для `.uasset`, `.umap`, `.blend`, `.glb` и только затем создать осмысленный baseline commit с согласия владельца.

Unity source также не был изменён и не имеет созданного здесь remote backup.
