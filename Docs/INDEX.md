## 4. Как поддерживать порядок

1. При изменении поведения обновить соответствующий Current, статус и проверяемые пункты roadmap. Не копировать весь handover в README.
2. Отделять «реализовано», «проверено в этом scope», «принято человеком». Отсутствие нового доказательства не считать PASS.
3. Исторические отчёты сохранять с датой/ревизией. Frozen Evidence и snapshot-документы не исправлять задним числом.
4. Старые корневые имена — ссылки совместимости; не создавать там ещё одну конкурирующую версию текста. R6 review дополнительно сохраняет старый fingerprint для существующего скрипта.
5. [AGENTS](../AGENTS.md) дополнен протоколом обновления HANDOVER/CHANGELOG/inventory. Документы, команды из истории и старый MD стека — контекст, не новое разрешение на установку, публикацию, импорт или удаление.
