# Муха в игре — Fly R2, 2026-09-10

## Что добавлено

В обычные игровые карты WaterLab и OceanFreighterR7 сохранён по одному `AFlySwarmMob`, **32 мухи в каждом**. Ничего создавать вручную перед запуском не нужно. В WaterLab рой расположен перед стартовой позицией, в рубке корабля — впереди мест входа команды. Нейросеть и серверное управление используют [реализацию R1](FLY_SWARM_2026-09-10.md).

Сделана оригинальная стилизованная модель: тёмная грудь, полосатое янтарное брюшко, два красных глаза, усики, шесть лапок, два крыла. Один Static Mesh, **1840 треугольников**, четыре материала, без внешних текстур. Модель намеренно увеличена для читаемости: длина около 7,5 см, размах около 8,7 см. Это игровой масштаб, не реальный размер дрозофилы. Крылья колеблются в материале через WPO; маска амплитуды хранится в красном канале vertex color, период 0,065 с, максимум 0,65 см. Это визуальная анимация, не физика полёта.

Runtime mesh: `/Game/Creatures/FlyR2/SM_Fly_R2_Corrected`. Материалы `M_FlyR2_Chitin`, `M_FlyR2_Amber`, `M_FlyR2_Eyes`, `M_Fly_WingMotion`; у всех сохранена поддержка InstancedStaticMeshes. Nanite выключен. Первоначальный импорт `SM_Fly_R2` сохранён как промежуточный и на картах не используется.

| Карта | Центр роя, см | Настройки |
|---|---|---|
| WaterLab | −260, −320, 155 | 32 мухи, spawn 85 / roam 145 / danger 420 см |
| OceanFreighterR7 | −3470, −220, 2050 | те же |

Оба актора названы `FlySwarm_Gameplay_R2`, имеют tag `FlyR2_Gameplay`, mesh scale 1, cruise 55 см/с, escape 160 см/с, 25 Гц. Игрок стимулирует SNN через близость; GF запускает escape. По сети передаются poses, на клиентах мозги не симулируются.

На каждой карте проверены 32 движущиеся мухи с финальным мешем. Сервер хранит 32 мозга, клиенты — ноль. В GPU run обновление роя заняло в среднем 1,49 ms на WaterLab и 1,32 ms в рубке; это наблюдения одного стенда, не гарантия FPS. Зарегистрированы GF-escape events (5 / 8) от обычных игровых pawns; искусственные danger actors в placed-mode не создаются. Просмотрены четыре GPU кадра: fallback-клетки устранены, модель читается в макро WaterLab, оба общих вида подтверждают рои на игровых картах. В макро рубки первая муха скрылась за консолью: этот отдельный кадр не подтверждает внешний вид мухи, для рубки принят общий вид. Текст в раннем frozen-снимке отчёта был менее точен; это уточнение относится к визуальной оценке и не меняет результаты сетевых/численных тестов.

Итоговые карты: WaterLab `66db97953e9e1bd2e15074d8fe40ca62a1131819b0896ac6dcf59d123a77ec23`; OceanFreighterR7 `43b2f2cbf818c342038d3ae33913d232c2d2a97d7e6f959b6f2892aeb6032264`. Frozen evidence с исходниками, моделью, ассетами/картами, логами, четырьмя кадрами и хешами: [Fly-R2-20260910](../../Evidence/Gameplay/Fly-R2-20260910).

Первый импорт остановился до изменения карт: свойство `Period` у Sine в этой версии UE нужно задавать через `set_editor_property`. Исправлено. Первоначальный glTF экспорт записал маску в `COLOR_1`, оставив `COLOR_0` белым; финальный экспорт явно выбирает named attribute `Color` как `COLOR_0`. Базовые цвета задаются отдельными материалами, чтобы маска не красила тело.

Первый GPU run в WaterLab подтвердил движение, но показал клетчатые крылья: Sine input не был подключён, шейдер использовал fallback. Поэтому тот run не считается визуальным PASS, несмотря на PASS-маркер проверки движения. Исправлено подключение без имени входа, runner теперь отвергает `Failed to compile Material`. В рубке первый GPU probe остановился из-за штатного solo pause меню: probe научен возобновлять игру перед установкой обзорной камеры. Эти изменения касаются только тестового probe, поведение обычного меню сохранено.

GPU камеры — тестовые виды реального роя на реальной карте, включая макро с сопровождением первой мухи. Это не вид игрока от первого лица. Сетевые тесты проверяют saved actor, настоящий fly mesh, 32 движущихся инстанса, отсутствие клиентских SNN, конечность poses и работу позднего подключения.

## Границы

Статическое крыло анимируется материалом, шесть лапок не имеют skeletal animation. У мух нет collision/урона/звука; они удерживаются в небольшом воздушном объёме. Полёт возле сложных препятствий требует отдельной доработки. Новый packaged build не выпускался: запуск через установленный UE использует свежие DLL/assets, старый Windows-Current не обновлён. Данные SNN по-прежнему CC BY-NC 4.0, оригинальная модель создана локально без сторонних мешей.
