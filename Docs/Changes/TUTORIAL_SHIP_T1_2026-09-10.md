## Выполнено

WaterLab — обычное начало игры и обучающая платформа. Задания общие, late join получает текущий snapshot, уход участника не обнуляет командный прогресс. Единственный фиксированный адрес назначения, один запрос ServerTravel. При синхронном отказе загрузки — явное сообщение ошибки; полноценного recovery UI нет.

HUD показывает этап, назначение следующей карты, направление/расстояние до ящика или зоны. Default Game/Server map и оба игровых launcher теперь WaterLab. Editor startup уже был WaterLab. [Play-Calmy.cmd](../../Scripts/Play-Calmy.cmd) — двойной клик на исходном ПК, PowerShell 7 + установленный UE; это Editor-game, не новый packaged exe. `start_game.ps1 -MapName OceanFreighterR7` — прямой вход на судно. `-CalmyLab` или существующий test-probe оставляет прежнюю лабораторию без обучения; исключение — специальный TutorialProbe.

Учебные грузы/помощник не копируются между картами. На судне четыре собственных груза, свой Миша, прежние R6B персонажи и R7 ship assets. Новых ассетов/программ/плагинов не скачивалось. Binary maps и материалы не менялись.
