## Что даёт сам MCP (по обзору TECHSY; сверить после входа)

Пять инструментов: `generate_image`, `generate_video` (асинхронно, до 15 с), `create_character` (Soul Character по 3–5 референсам, обучение 3–5 мин), `get_generation_status`, `list_characters`. Генерации идут по одной. Примерная цена: изображения — Nano Banana Pro ~2 кредита, Flux 2 ~6, GPT Image 2 ~8, Soul V2 ~10; видео — Seedance 2.0 ~30, Kling 3.0 ~50, Veo 3.1 ~60. Тот же обзор упоминает бесплатные 150 кредитов в месяц (данные на май 2026, после переименования тарифов не подтверждены). Звук в списке инструментов не значится, хотя в описании подключения к Claude он заявлен — проверить.

Полезно проекту: целевые кадры настроения для художественного прохода, декали и таблички судна, иконки HUD и экранов мостика, фоны меню и загрузки, портреты экипажа, материалы для Steam и тизер. Изображения приходят без альфа-канала и без PBR-карт — фон и карты доводить отдельно.

## Главное ограничение: 3D недоступно через MCP

**3D Jutsu — отдельная браузерная среда, через MCP-сервер не работает.** Через MCP идут только генерация изображений и видео (30+ моделей). То есть подключение MCP к Claude Code само по себе **не даёт мешей для Unreal**.

3D-возможности (в вебе): text-to-3D и сцены по референсу, редактирование объектов, света и камер, анимация, библиотека примитивов и персонажей Mixamo. Экспорт сцены: GLB, MP4, кадр. Image-to-3D и оснастку скелетом выполняют сторонние движки — Meshy, Tripo, SAM 3 от Meta. Параметры меша: 100–300 000 треугольников (по умолчанию ~30 000), quad или триангуляция, опционально PBR-карты (metallic, roughness, normal). Генерация 3D платная и асинхронная; текстурирование, PBR, оснастка и анимация добавляют кредиты, больше полигонов — дороже. Точная цена за модель в открытых источниках не публикуется. Ограничение по существу: **модель воспроизводит только то, что есть на исходном изображении**.

Есть аддон для Blender — это ближе к нашему конвейеру (Blender → GLB → UE), но он тоже вне MCP.

## Лицензия (важно для распространения игры)

- Higgsfield **не претендует на владение** промптами и результатами; коммерческое использование разрешено **на всех тарифах**, отдельную лицензию покупать не нужно, атрибуция не требуется.
- Права на уже сгенерированное и выгруженное **сохраняются после отмены подписки и удаления аккаунта**.
- Результаты **не гарантированы уникальными**: та же модель может выдать похожее другому пользователю. Для CC0-наборов (Poly Haven, Kenney, ambientCG) это тоже верно, но там есть локальный provenance-снимок, а здесь его придётся делать самим.
- Higgsfield оставляет за собой право **обучать модели на загруженном и сгенерированном контенте на всех тарифах, кроме Enterprise**. Для закрытых материалов проекта это риск: концепты и референсы корабля уйдут в обучение.
- Запрещено использовать результаты Higgsfield для обучения своих моделей без письменного разрешения.

## Вывод для проекта

Higgsfield решает задачу «реквизит и концепты», а не «геометрия корабля»: сгенерированный меш повторяет картинку и требует ручной доводки — топология, масштаб, точка опоры, коллизия, LOD, настройки Nanite. Это тот же путь, что у [Poly Haven](../Current/ASSETS.md), через `Scripts/import_polyhaven_ship_props.py`.

При возврате к теме порядок такой:

1. Оплатить тариф (для MCP и Supercomputer кредиты тратятся всегда — считать по числу генераций, а не по «безлимиту»).
2. Пройти OAuth, проверить состав инструментов сервера.
3. Тест на 2–3 предметах: генерация → GLB → импорт существующим скриптом → сравнение с моделями Poly Haven по качеству и трудозатратам.
4. Завести локальный provenance-файл рядом с `SourceAssets/ThirdParty/PolyHaven/LICENSE-PROVENANCE-2026-09-15.md`: промпт, дата, модель, хеши файлов.

Отдельно от Higgsfield и **без затрат**: основной резерв качества картинки — свет, экспозиция, цветокоррекция и износ материалов, а не новые меши. По [Ship Metal R1](SHIP_METAL_R1_2026-09-06.md) арт и освещение корабля не завершены, пересвет светильников и экранов остаётся открытой задачей. Проверять проходы кадрами через `UCalmyPhotoTourProbe` и контактные листы.
